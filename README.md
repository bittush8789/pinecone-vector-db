## Pinecone Vector DB

A hands-on demo project showcasing how to use the **Pinecone vector database** for semantic search and RAG (Retrieval-Augmented Generation) workflows with modern LLM tools like LangChain and OpenAI embeddings.

---

## 🚀 Project Overview

This repository contains examples and demonstrations of building vector search pipelines using:

- **Pinecone** – Scalable vector database
- **LangChain** – Modular framework for LLM applications
- **OpenAI Embeddings & Chat models** – Generate and search semantic embeddings

You can use this as a reference or starter template for real-world applications involving:
✔ Semantic search  
✔ Vector embeddings  
✔ RAG workflows  

---

## 📁 Included Content

| File / Folder | Description |
|---------------|-------------|
| `notebooks/` | Demo notebooks illustrating vector DB usage |
| `scripts/` | Python scripts for building embeddings and vector storage |
| `documents/` | Example source text / PDF data for embedding and search |
| `.gitignore` | Ignores secrets and environment configs |

---

## 🧠 Features

✅ Load and preprocess documents  
✅ Convert text to embeddings using OpenAI  
✅ Store embeddings in Pinecone  
✅ Perform semantic search queries  
✅ Retrieve context for LLM-powered answers
